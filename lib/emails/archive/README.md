# Archived emails

One-off emails that were sent once and are no longer wired into the app, admin
test-sends or previews. Kept for reference (copy, structure, history).

- `member-update.ts`: "First matches tomorrow!" before the first round (June 2026)
- `pending-followup.ts`: nudge to members stuck in pending before the August round (July 2026)
- `perks-announcement.ts`: Post Perks launch heads-up (September 2026)

They still compile against `../base`, so a type error here means `base.ts`
changed shape, not that something is broken in production. The scripts that
sent them are in `scripts/archive/`.
